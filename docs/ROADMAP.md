# Roadmap

## v0.1.0 (this package)

- Claude Code skill for a bounded end-to-end orchestration protocol.
- Nine specialized agent definitions with preferred model family aliases.
- Optional task-plan validator rejecting missing requirements, cycles and conflicting parallel paths.
- Marketplace manifest, local installation instructions, static tests and GitHub CI.

## Proposed next increments

- v0.2: formal JSON schema and machine-readable run ledger (only with explicit opt-in).
- v0.3: additional official example repositories and measured quality/cost comparisons.
- v0.4: optional standardized handoff report generator with zero telemetry.

Future features are not included in the current package; all releases require a live Claude Code smoke test before being advertised as validated end to end.
